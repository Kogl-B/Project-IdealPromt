ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ЗАПУСКУ ПРОГРАММЫ "ГЕНЕРАТОР ПИСЕМ"
==================================================================

ТРЕБОВАНИЯ:
-----------
- Python 3.8 или выше (скачать с https://www.python.org/downloads/)
- Windows 7/8/10/11

УСТАНОВКА:
----------
1. Скачайте и установите Python с официального сайта python.org
   ВАЖНО: При установке поставьте галочку "Add Python to PATH"!

2. Распакуйте все файлы программы в одну папку

3. Откройте командную строку (cmd) в папке с программой:
   - Нажмите Shift + Правая кнопка мыши в папке
   - Выберите "Открыть окно команд здесь" или "Открыть PowerShell здесь"

4. Установите необходимые библиотеки командой:
   pip install -r requirements.txt

ЗАПУСК:
-------
Вариант 1: Двойной клик по файлу run_app.bat

Вариант 2: Запуск через командную строку:
   python letter_generator_app.py

СТРУКТУРА ФАЙЛОВ:
-----------------
letter_generator_app.py - главный файл программы
requirements.txt - список необходимых библиотек
run_app.bat - файл для быстрого запуска
INSTALL.txt - эта инструкция

ИСПОЛЬЗОВАНИЕ:
--------------
1. При первом запуске выберите Excel-файл с данными
2. Выберите шаблон Word для писем
3. Укажите папку для сохранения готовых писем
4. Нажмите "Начать обработку"
5. Программа запомнит пути к файлам для следующего запуска

ВОЗМОЖНЫЕ ПРОБЛЕМЫ:
-------------------
Если программа не запускается:
- Убедитесь, что Python установлен и добавлен в PATH
- Проверьте, что установлены все библиотеки из requirements.txt
- Запустите через командную строку, чтобы увидеть ошибки

Если письма генерируются неправильно:
- Проверьте формат Excel-файла (должны быть колонки: ФИО, Адрес, и т.д.)
- Убедитесь, что в Word-шаблоне есть соответствующие плейсхолдеры

ПОДДЕРЖКА:
----------
При возникновении проблем создайте issue на GitHub или обратитесь к разработчику.
