## 💡 Основные концепции / Core Concepts

### Что такое хороший промт? / What is a Good Prompt?

Хороший промт это:
- **Конкретный** / Specific — четко описывает что нужно
- **Структурированный** / Structured — организован логично
- **Полный** / Complete — содержит всю нужную информацию
- **Понятный** / Clear — не оставляет места для неоднозначности

### Анатомия промта / Anatomy of a Prompt

```
[РОЛЬ] — кто AI в этом контексте
[КОНТЕКСТ] — какая ситуация
[ЗАДАЧА] — что нужно сделать
[ТРЕБОВАНИЯ] — как это сделать
[ФОРМАТ] — в каком виде представить
```

**Пример / Example:**
```
[РОЛЬ]: Ты опытный учитель Python
[КОНТЕКСТ]: Я начинающий программист, изучаю циклы
[ЗАДАЧА]: Объясни как работает цикл for
[ТРЕБОВАНИЯ]: Используй простые слова, добавь 3 примера
[ФОРМАТ]: Объяснение + примеры с комментариями
```

## 🛠️ Практические советы / Practical Tips

### Совет 1: Начинайте просто / Start Simple

Не пытайтесь создать идеальный промт сразу. Начните с базового и улучшайте.

**Базовый / Basic:**
```
Напиши функцию для сортировки списка
```

**Улучшенный / Improved:**
```
Напиши функцию на Python для сортировки списка целых чисел по возрастанию.
Включи обработку ошибок и docstring. Используй встроенную функцию sorted().
```

### Совет 2: Добавляйте примеры / Add Examples

AI лучше понимает, когда видит примеры.

**Без примеров / Without Examples:**
```
Преобразуй текст в формальный стиль
```

**С примерами / With Examples:**
```
Преобразуй текст в формальный стиль.

Пример:
Входные данные: "Привет! Как дела?"
Выходные данные: "Здравствуйте! Как поживаете?"

Теперь преобразуй: "Скинь мне файл, плз"
```

### Совет 3: Будьте специфичны / Be Specific

Вместо расплывчатых просьб, указывайте детали.

❌ **Плохо / Bad:**
```
Помоги с кодом
```

✅ **Хорошо / Good:**
```
Помоги исправить ошибку "TypeError" в моей Python функции 
для обработки JSON. Вот код: [код]
```

### Совет 4: Указывайте формат / Specify Format

Скажите как хотите получить ответ.

```
Предоставь ответ в следующем формате:
1. Краткое резюме
2. Пошаговое решение
3. Пример кода
4. Объяснение
```

## 📚 Шпаргалка / Cheat Sheet

### Полезные фразы / Useful Phrases

**Для объяснений / For Explanations:**
- "Объясни простыми словами" / "Explain in simple terms"
- "Используй аналогии" / "Use analogies"
- "Приведи примеры" / "Provide examples"

**Для кода / For Code:**
- "Включи комментарии" / "Include comments"
- "Добавь обработку ошибок" / "Add error handling"
- "Следуй PEP 8" / "Follow PEP 8"

**Для структуры / For Structure:**
- "В виде списка" / "As a list"
- "Пошагово" / "Step by step"
- "В формате таблицы" / "In table format"

### Типичные ошибки / Common Mistakes

1. ❌ Слишком расплывчато / Too vague
2. ❌ Слишком много задач сразу / Too many tasks at once
3. ❌ Отсутствие контекста / Missing context
4. ❌ Неясный ожидаемый результат / Unclear expected result

## 🎯 Ваш первый промт / Your First Prompt

Давайте создадим промт вместе! / Let's create a prompt together!

**Шаг 1:** Определите задачу
```
Что вы хотите сделать?
Например: "Написать функцию для проверки email"
```

**Шаг 2:** Добавьте детали
```
- Какой язык программирования?
- Какие требования?
- Что должна делать функция?
```

**Шаг 3:** Структурируйте
```
Напиши функцию на Python для проверки email адреса.

Требования:
- Использовать регулярные выражения
- Проверять базовый формат (есть @ и домен)
- Возвращать True/False
- Включить docstring и примеры использования

Формат ответа:
1. Код функции
2. Объяснение логики
3. Примеры использования
```

**Готово!** Это хороший промт для начала.
