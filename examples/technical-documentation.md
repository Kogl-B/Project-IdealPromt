# Пример промта: Генератор технической документации / Prompt Example: Technical Documentation Generator

**Автор / Author:** Project-IdealPromt Team  
**Категория / Category:** Написание / Writing  
**Сложность / Difficulty:** Средний / Intermediate

## 🎯 Назначение / Purpose

Создание структурированной технической документации для кода, API или библиотек с учетом лучших практик.

Creating structured technical documentation for code, APIs, or libraries following best practices.

## 📋 Промт / Prompt

```
Ты технический писатель с опытом в создании документации для разработчиков.

Создай техническую документацию для следующего [код/API/библиотека]:

[КОД ИЛИ ОПИСАНИЕ]

Документация должна включать:

1. **Обзор (Overview)**
   - Краткое описание (2-3 предложения)
   - Основная цель и применение
   - Ключевые возможности

2. **Установка (Installation)**
   - Требования и зависимости
   - Пошаговая инструкция по установке
   - Проверка успешной установки

3. **Быстрый старт (Quick Start)**
   - Минимальный рабочий пример
   - Ожидаемый результат
   - Следующие шаги

4. **API Reference / Справочник**
   Для каждой функции/метода/класса:
   - Назначение
   - Параметры (тип, описание, обязательность)
   - Возвращаемое значение
   - Примеры использования
   - Возможные исключения/ошибки

5. **Примеры использования (Usage Examples)**
   - Базовые сценарии
   - Продвинутые сценарии
   - Часто встречающиеся задачи

6. **Лучшие практики (Best Practices)**
   - Рекомендации по использованию
   - Что делать и чего избегать
   - Оптимизация производительности

7. **Устранение неполадок (Troubleshooting)**
   - Частые проблемы и решения
   - FAQ
   - Где получить помощь

Формат: Markdown с четкой структурой заголовков, блоками кода и примерами.

Стиль: Ясный, технически точный, дружественный к начинающим.
```

## 📊 Пример вывода / Example Output

```markdown
# Calculator Library

## Overview

Calculator Library — это легковесная математическая библиотека для Python,
предоставляющая базовые и расширенные математические операции с поддержкой
цепочки вычислений.

**Ключевые возможности:**
- Базовые арифметические операции
- Цепочка вычислений
- Обработка ошибок
- Поддержка десятичных чисел

## Installation

### Requirements
- Python 3.7+
- pip

### Install via pip
```bash
pip install calculator-lib
```

### Verify installation
```python
import calculator
print(calculator.__version__)
```

## Quick Start

```python
from calculator import Calculator

calc = Calculator()
result = calc.add(5).multiply(3).subtract(2).result()
print(result)  # Output: 13
```

## API Reference

### Calculator Class

#### `add(value: float) -> Calculator`

Добавляет значение к текущему результату.

**Parameters:**
- `value` (float): Число для сложения

**Returns:**
- `Calculator`: Возвращает self для цепочки вызовов

**Example:**
```python
calc = Calculator()
calc.add(10).add(5)  # Result: 15
```

**Raises:**
- `TypeError`: Если value не число

[и так далее...]
```
