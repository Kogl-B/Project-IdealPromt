## 🎯 Назначение / Purpose

Помогает систематически находить и исправлять ошибки в коде.

Helps systematically find and fix bugs in code.

## 📋 Промт / Prompt

```
Ты эксперт по отладке кода на [язык программирования].

Я столкнулся с ошибкой в моем коде. Помоги мне её диагностировать и исправить.

**Код:**
```
[ВАШ КОД]
```

**Ошибка:**
```
[СООБЩЕНИЕ ОБ ОШИБКЕ]
```

**Контекст:**
- Что я пытаюсь сделать: [описание]
- Что происходит вместо этого: [описание]
- Что я уже пробовал: [описание]

Пожалуйста:
1. Объясни, что вызывает ошибку простыми словами
2. Покажи, где именно проблема в коде
3. Предложи исправленную версию кода
4. Объясни, почему это исправление работает
5. Дай советы, как избежать подобных ошибок в будущем
```

## 📊 Пример вывода / Example Output

```
**АНАЛИЗ ОШИБКИ**

🔍 **Что вызывает ошибку:**
Ошибка IndexError возникает потому, что вы пытаетесь получить доступ 
к элементу списка по индексу, который не существует. В вашем коде список 
имеет 5 элементов (индексы 0-4), но вы пытаетесь обратиться к индексу 5.

📍 **Где именно проблема:**
Строка 12: `result = my_list[i]`
Когда i = 5, список заканчивается на индексе 4.

✅ **Исправленный код:**
```python
# Было:
for i in range(len(my_list) + 1):  # +1 создает проблему!
    result = my_list[i]

# Должно быть:
for i in range(len(my_list)):  # Убираем +1
    result = my_list[i]

# Или еще лучше (более питоничный способ):
for item in my_list:
    result = item
```

💡 **Почему это работает:**
range(len(my_list)) генерирует числа от 0 до len(my_list)-1,
что точно соответствует валидным индексам списка.

🛡️ **Как избежать в будущем:**
1. Используйте прямую итерацию (for item in list) когда не нужен индекс
2. Если нужен индекс, используйте enumerate(): for i, item in enumerate(my_list)
3. Всегда проверяйте, что индекс находится в допустимом диапазоне
4. Используйте try-except для обработки возможных IndexError
```
