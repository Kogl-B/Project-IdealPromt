# Пример промта: Помощник в код-ревью / Prompt Example: Code Review Assistant

**Автор / Author:** Project-IdealPromt Team  
**Категория / Category:** Программирование / Programming  
**Сложность / Difficulty:** Средний / Intermediate

## 🎯 Назначение / Purpose

Этот промт помогает провести тщательное код-ревью с фокусом на качество кода, безопасность и лучшие практики.

This prompt helps conduct thorough code reviews with a focus on code quality, security, and best practices.

## 📋 Промт / Prompt

```
Ты опытный Senior Software Engineer с экспертизой в [язык программирования]. 
Проведи детальное код-ревью следующего кода:

[КОД]

Пожалуйста, проанализируй код по следующим критериям:

1. **Читаемость и стиль**
   - Насколько понятен код?
   - Соответствует ли стандартам кодирования?
   - Достаточно ли комментариев?

2. **Производительность**
   - Есть ли узкие места производительности?
   - Можно ли оптимизировать алгоритмы?

3. **Безопасность**
   - Есть ли потенциальные уязвимости?
   - Правильно ли обрабатываются входные данные?

4. **Обработка ошибок**
   - Все ли ошибки обрабатываются?
   - Корректны ли сообщения об ошибках?

5. **Тестируемость**
   - Легко ли тестировать код?
   - Есть ли зависимости, которые нужно мокать?

6. **Лучшие практики**
   - Следует ли код принципам SOLID?
   - Используются ли паттерны проектирования правильно?

Для каждой найденной проблемы предоставь:
- Описание проблемы
- Уровень серьезности (критический/высокий/средний/низкий)
- Конкретное предложение по улучшению с примером кода

Также укажи, что сделано хорошо в этом коде.
```

## 🔧 Параметры / Parameters

- **[язык программирования]:** Укажите конкретный язык (Python, JavaScript, Java и т.д.)
- **[КОД]:** Вставьте код для ревью
- Можно добавить специфичные критерии для вашего проекта

## 💡 Контекст использования / Usage Context

Используйте этот промт когда:
- Нужно проверить свой код перед коммитом
- Хотите получить второе мнение
- Обучаетесь написанию качественного кода
- Нужен структурированный анализ

Use this prompt when:
- Need to check your code before committing
- Want a second opinion
- Learning to write quality code
- Need structured analysis

## 📊 Пример вывода / Example Output

```
**АНАЛИЗ КОД-РЕВЬЮ**

✅ **Что сделано хорошо:**
- Четкие имена переменных
- Хорошая структура функций
- Используется list comprehension для краткости

⚠️ **Найденные проблемы:**

1. **Отсутствие обработки ошибок** [ВЫСОКИЙ]
   Проблема: Функция не обрабатывает случай пустого списка
   
   Текущий код:
   ```python
   def calculate_average(numbers):
       return sum(numbers) / len(numbers)
   ```
   
   Рекомендация:
   ```python
   def calculate_average(numbers):
       if not numbers:
           raise ValueError("Список не может быть пустым")
       return sum(numbers) / len(numbers)
   ```

2. **Неэффективный алгоритм** [СРЕДНИЙ]
   Проблема: Вложенные циклы создают O(n²) сложность
   
   Рекомендация: Использовать set для O(n) сложности
   [и так далее...]
```

## ⚙️ Варианты и модификации / Variations and Modifications

### Для начинающих / For Beginners
Упростите критерии, сфокусируйтесь на основах:
- Читаемость
- Базовая обработка ошибок
- Простые оптимизации

### Для специализированных проверок / For Specialized Checks
Добавьте специфичные критерии:
- Проверка на SQL-инъекции (для веб-приложений)
- Проверка многопоточности (для concurrent кода)
- Проверка memory leaks (для системного программирования)

### Быстрое ревью / Quick Review
Сократите до 3 основных критериев:
- Безопасность
- Производительность
- Читаемость
