IdealPromt of AI 

## 📥 Скачать готовую программу

**Генератор Писем** - готовое приложение для автоматической генерации писем.

### Способы установки:

1. **Скачать .exe (Windows)** - без установки Python
   - Перейдите на вкладку [Releases](https://github.com/Kogl-B/Project-IdealPromt/releases)
   - Скачайте последнюю версию `LetterGenerator.exe`
   - Запустите двойным кликом

2. **Скачать артефакт сборки**
   - Откройте вкладку [Actions](https://github.com/Kogl-B/Project-IdealPromt/actions)
   - Выберите последнюю успешную сборку
   - Скачайте `LetterGenerator-Windows.zip` из Artifacts

3. **Запустить из исходников** (для разработчиков)
   ```bash
   pip install -r requirements.txt
   python letter_generator_app.py
   ```
