# Letter Generator - Генератор Писем

Программа для автоматической генерации персонализированных писем на основе данных из Excel и шаблонов Word.

## Возможности

- ✅ Чтение данных из Excel файлов
- ✅ Генерация писем на основе Word шаблонов
- ✅ Автоматическая подстановка данных (ФИО, адреса, и т.д.)
- ✅ Сохранение путей к файлам для последующих запусков
- ✅ Удобный графический интерфейс
- ✅ Логирование всех операций

## Установка и запуск

### Способ 1: Запуск через Python (рекомендуется)

1. Установите Python 3.8+ с [python.org](https://www.python.org/downloads/)
   - ⚠️ **ВАЖНО**: При установке поставьте галочку "Add Python to PATH"

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите программу:
   - **Windows**: Двойной клик по `run_app.bat`
   - **Командная строка**: `python letter_generator_app.py`

### Способ 2: Создание .exe файла (только для Windows)

1. Запустите `build_exe.bat` на Windows-машине
2. Исполняемый файл появится в папке `dist/LetterGenerator.exe`
3. Скопируйте `.exe` файл на любой компьютер и запускайте без установки Python

## Использование

1. При первом запуске:
   - Выберите Excel-файл с данными
   - Выберите Word-шаблон для писем
   - Укажите папку для сохранения готовых писем

2. Нажмите "Начать обработку"

3. Программа запомнит все пути для следующего запуска

## Формат данных

### Excel файл должен содержать колонки:
- ФИО
- Адрес
- Другие поля по необходимости

### Word шаблон должен содержать плейсхолдеры:
- `{ФИО}` - для замены имени
- `{Адрес}` - для замены адреса
- И т.д.

## Устранение неполадок

**Программа не запускается:**
- Убедитесь, что Python установлен и добавлен в PATH
- Проверьте установку библиотек: `pip list`
- Запустите через командную строку для просмотра ошибок

**Письма генерируются неправильно:**
- Проверьте формат Excel-файла
- Убедитесь, что плейсхолдеры в Word-шаблоне совпадают с названиями колонок
